# Onglet template

LMGC90_GUI vous permet de créer des avatars à partir d'une bibliothèque déjà configurer, vous avez aussi la possibilité de créer des nouvelles templates afin de pouvoir les réutiliser pour vos modèles.

![](captures/templates.JPG)

## Exemples d'utilisation

L'onglet est divisé par deux, partie gauche qui est représenté par un arbre qui contient les avatars, et la partie droite qui contient les propriétés des avatars.
Si je déroule : 
- "Particules simples" -> : 
  - " Petit disque"
  - " Disque moyen"
  - "Grand disque"
Pour mon cas je choisis "Petit disque", puis je clique sur le bouton "Créer Avatar "

![](captures/templates_pt_avatar.JPG)


Vous avez aussi la possibilité de créer un nouveau template en cliquant sur le bouton "Nouveau template"

![](captures/templates_new.JPG)
