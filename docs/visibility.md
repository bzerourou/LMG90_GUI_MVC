# Tables de Visibilité

Cette section est dédiée à créer des tables de visibilités qui sert de configuration aux détection des contacts.

## Paramètres
- Corps candidat / antagoniste
- Contacteurs : type de contacteurs qui vont interagir
- Couleurs : 
- Loi de comportement
- Distance d’alerte : distance qui permet d'alerter le solveur
